# NMAX Garage App — PWA

GitHub Pages URL:
https://darwinlorenzana.github.io/nmax-garage-app/

The PWA shell embeds the existing Google Apps Script web app:

https://script.google.com/macros/s/AKfycbzzng07TD64svTZPlViB8Oeq7laeY5G-y-pCFvteAzgvdek9HCS8cP0vrK6KB7NTLE/exec

## Deployment

1. Create/use the GitHub repository named `nmax-garage-app`.
2. Upload the contents of this folder to the repository root.
3. Enable GitHub Pages for the repository.
4. Use the GitHub Pages URL:
   https://darwinlorenzana.github.io/nmax-garage-app/
5. On Android Chrome, open the GitHub Pages URL.
6. Choose **Install app** / **Add to Home screen**.

Do not install the Apps Script `/exec` URL directly. The GitHub Pages URL owns the manifest and icon files.

## Backend

The Apps Script backend remains the application backend. This PWA package does not replace `Code.gs`.
